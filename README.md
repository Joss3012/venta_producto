#  Tienda de Ropa Deportiva

##  Descripción del proyecto

Este proyecto consiste en el desarrollo de una página web orientada a la venta de ropa deportiva. Su propósito es presentar una interfaz visual atractiva y organizada para que los usuarios puedan conocer los productos y obtener información sobre la tienda.

La página cuenta con una sección de contacto que permite conocer la ubicación del establecimiento y acceder a redes sociales y enlaces relacionados con los desarrolladores del proyecto.

##  Objetivos

- Desarrollar una página web para una tienda de ropa deportiva.
- Crear una interfaz organizada y fácil de navegar.
- Aplicar estilos personalizados mediante CSS.
- Incorporar imágenes e iconos para mejorar la presentación visual.
- Facilitar el acceso a la información de contacto de la tienda.

##  Tecnologías utilizadas

- **JSP (JavaServer Pages):** estructura y generación dinámica de contenido web.
- **CSS3:** diseño, estilos y presentación visual.
- **JavaScript:** incorporación de funcionalidades interactivas, si están implementadas en el proyecto.
- **HTML5:** organización de los elementos de la página web.

##  Instalación y ejecución

Para ejecutar el proyecto, sigue estos pasos:

1. Descarga o clona el repositorio desde GitHub.

   ```bash
   git clone URL_DE_TU_REPOSITORIO
   ```

2. Abre el proyecto en Visual Studio Code o en el entorno de desarrollo que utilices.

3. Configura un servidor compatible con JSP, como Apache Tomcat.

4. Despliega el proyecto en el servidor.

5. Abre la dirección local proporcionada por el servidor para visualizar la página web.

**Nota:** el archivo `index.jsp` necesita un servidor compatible con JSP; no basta con abrirlo directamente en el navegador como un archivo HTML.
